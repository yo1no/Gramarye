## 性能與第一失敗

- 純固定 heap 候選以 JDK 21 `-Xmx48m` 分行程跑 projection/owner reservation/reclaim。不把 M1/C 已完成的 probe 歸入 V0。測 default/hard、很多小或少量大、old/new 版本 churn 256 次、MAX+1 及 stop 後清零。用兩個完整 Unit、兩 Damage、一 Create、兩套 128-byte triplet、exact Manifest 的最大合法 fixture 實測 1089，另以第三 Unit、depth 2、129-byte ID、synthetic charge 1090、負 length 與 checked overflow 分別拒絕。48 MiB 結果分別記 lease/index、P5 instance/event、P9 binding、projection object graph、cold C scratch、M1 graph/image、diagnostics ring，各自去重保留與 temporary high-water。使用實際 charged/retained data、heap 水位和 GC，滿量不得 OOM。偵測 VM Error 的 primacy 與 owner fence 另外用 injected faults，避免污染正常訊號。
- Native 定界按工程唯一起動 tuple。用固定 Java/platform/runner/world 的 legacy-only/reference 與 mixed 各執行至少 2,000 ticks warmup、10,000 ticks 採樣；獨立測 cold 從第一個 snapshot，以及準備未完成跨8 ticks 的拒絕。保存 P50/P95/P99/max、heap retained/allocated、GC、sweep candidates/sections、preflight bounded loading、P8 scan/actual sends、Native F/R、P11 write/dirty/true timings。Native eligibility 工作不因量測延遲。工程 provisional ceiling 接受 threshold 為 mixed p99 ≤50ms，且 matched legacy-only 基線 p99 增量 ≤5ms，legacy 與合法 V deadlines/原生 hit schedule 零違反。全量鬆綁不可用平均值兜底；cold gate timestamp、stop closure、回穩 plateau、首次 failure 對應真 counter。
- 不把 OS/online/game fault 重標產品 PASS。保存首次 raw 日誌、真成果、source/config、clock/candidate id、fault taxonomy。用有原因的修正重驗相依 cases，最後 required gates。Candidate CI、main CI 必須各驗 final SHA，CI 不代替真正認證在線用例。敏感資料不進 source/log/CI artifacts，場景只用去識別化 tags。
