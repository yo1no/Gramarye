## 7. A05 Minimal Observability Surface 採用

2026-11-17（Asia/Taipei）。依使用者明示採用，在原 S1 candidate `4d1417008c55cf60fcbc4cd577364671c6fe8825`、tree `ab01c5ea90f08c1237a3d731ec0731fd65a87426` 上登錄下列最小 A05 唯讀觀測。僅在本節明列宣告、constructor wiring 與 caller 範圍取代 §2／§6 的原 inventory。S1 已接受 U1／U2 保留原來源及結果，不重新執行；其 test composition 只同步既有 constructor 的 NOOP 參數。其餘 runtime、P6 receipt、P8、Mana、P11、K1、config、限額與 55 列接受條件全部保持。

新增唯一 observer `com.yo1no.gramarye.A05Observer` 為 final package-private concrete class，無 interface implicit-public methods 或控制型 override。唯一 package-private constructor 接受三個 `java.util.function.Consumer`，依序只接收下面三種 immutable scalar observation。Production 固定引用 `static final A05Observer NOOP = new A05Observer(null, null, null)`；三個 private final receiver fields 不持有任何 player／server／level／entity／connection／Mana／P11 scope／catalog lease／native port／transport。Qualification 的 receivers 僅指向具名 recorder 的純 scalar 記錄方法，不捕獲 scene 或遊戲物件。
